**Codex Chat Links** for Logseq Desktop 2.0.2 DB graphs on macOS. Paste a Codex thread URL into a block to insert a clickable Markdown link and show an inline icon.

This version packages the plugin for Logseq Marketplace. It reads the optional local title index through Logseq’s scoped FileStorage API. Install the macOS helper to use chat titles from this Mac. Until a title is available the link uses a short thread ID. See the README for the setup command and uninstall instructions.
